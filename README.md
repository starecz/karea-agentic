# karea-agentic

[Karea](https://karea.app) for Claude Code: mods, skills and plugins.

## Install

```
/plugin install karea --marketplace starecz/karea-agentic
```

## Plugins

| Plugin | What it does |
| --- | --- |
| `karea` | Shows whether your active Karea task is in sync with the session: hint-line chip, "behind" band with Sync now, changed-in-Karea alerts, task pane and a `/ksync` command. |

## Develop

```
claude plugin validate plugins/karea
claude plugin test plugins/karea
```
